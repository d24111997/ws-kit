# Vault — Map of Content (MOC)

> Vault này là **shared brain** giữa các project.
> Mỗi project vẫn độc lập, vault chỉ chứa phần chung + trao đổi cross-project.
>
> Bắt đầu từ [[AGENTS.md]] để hiểu cách vault hoạt động.

---

## 📁 Folders

| Folder | Nội dung |
|--------|----------|
| `00_TASKS_THIS_WEEK/` | Workspace tạm cho task trong tuần |
| `01_Project/` | Tổng quan dự án, tech stack |
| `02_Architecture/` | Kiến trúc, DB schema, API contract, ADRs |
| `03_Flows/` | Luồng nghiệp vụ chi tiết |
| `04_Research/` | Nghiên cứu kỹ thuật |
| `05_Meeting_note/` | Biên bản họp |
| `06_Backlog/` | Backlog items |
| `07_Infra/` | Hạ tầng, deploy, services |
| `08_Behavior-spec/` | Behavior specs |
| `09_Known_Issues/` | Known issues |
| `10_unclassified/` | Chưa phân loại |
| `11_Testing/` | Test docs (templates + test plans + scenarios + matrices) |
| `12_bug/` | Bug reports |
| `_templates/` | Template files |
| `_diagrams/` | Sơ đồ |

---

## 🗂️ Templates

- `_templates/_Index.md` — toàn bộ template (note, ADR, backlog, handover...)
- `11_Testing/templates/_Index.md` — template test docs (scenario, validation matrix, test plan...)
