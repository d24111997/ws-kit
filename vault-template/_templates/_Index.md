# Templates

| File | Nội dung |
|------|----------|
| `note-template.md` | Template ghi chú mặc định |
| `adr-template.md` | Template Architecture Decision Record (Context → Decision → Why → Consequences) |
| `backlog-template.md` | Template backlog item |
| `ki-template.md` | Template known issue |
| `handover-template.md` | Template handover cuối session |
| `context-seed-template.md` | Context seed — 1 file AI đọc đầu tiên cho feature lớn |
| `overview-doc-template.md` | **Template tài liệu tổng quan (overview/context/architecture)** — frontmatter + nội dung timeless + changelog theo thứ tự thời gian. **MỌI tài liệu tổng quan trong hệ thống phải follow.** |
